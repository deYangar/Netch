Netch 2.1 —— 订阅解析与测速精度大版本。

围绕「订阅拉下来就能用、测速数字可信、启动不卡」三个方向的整体升级：

- **Clash YAML 订阅原生支持**：直接订阅 Clash 配置，全部协议类型自动解析，订阅自带的 DNS 与域名映射一并接管生效，不再只当节点列表用
- **每订阅独立解析设置**：自定义 DoH 上游与「域名 → IP」映射，按订阅单独配置——被污染解析不了的机场，指定自己的 DoH 就能连上
- **测速改走真实链路**：节点测速经实际代理出站握手实测，不再本地探测；同一服务器的节点自动分组限速轮测，单节点连测三次取中位数，数字贴近真实使用
- **多节点订阅冷启动提速**：DNS 解析失败快速记忆 + 域名并行解析，大订阅（百级节点）首次解析从半分钟级降到秒级
- **外部资源下载容灾**：规则集、内核、更新包的主源与备源分属不同 CDN 服务商，单一 CDN 故障自动切换，下载不再看运气

兼容 2.0 的全部数据（设置、节点、订阅、模式直接沿用）。

> 进程代理与 TUN 模式需要管理员权限运行。
