Netch 2.1.1 —— 发版形态调整与打包修复。

- **发版形态变更：改用 zip 压缩包分发** —— 安装包从单个 exe 换为内含完整程序文件夹的 zip，解压即用；程序、内核、归属地数据库全部随包就位，全新环境首次使用无需在线下载等待，此后新版本均采用此形态发布。旧版本程序内直接检查更新即可平滑升级，数据不受影响
- **修复 2.1.0 安装包打包遗漏** —— 单文件安装包在全新环境下启动代理时报「缺少文件或运行库」，系安装包未携带进程代理所需的系统组件；本版起组件随包完整分发，全新环境开箱即用

> 进程代理与 TUN 模式需要管理员权限运行。
