Netch 2.0 —— WPF 重制版首个公开版本。

fork 自 [NetchX/Netch](https://github.com/netchx/netch) 1.x，界面与功能整体重制：

- **全新界面**：WPF Fluent 风格，浅色 / 深色 / 跟随系统三态主题，中英双语即时切换
- **双内核**：sing-box 主力 + Xray 自动兜底，内核直接嵌入 exe——首次启动自动释放，无需另外下载
- **进程代理 / TUN 两种模式**：没有全局开关，选哪个模式文件、启动就进哪种模式
- **订阅管理**：链接订阅一键拉取、分组管理、单条 / 全量更新、节点测速
- **分流规则**：规则集（远程 .srs / 本地文件）+ 模式编辑器（域名 / IP / 端口 / 协议 / 进程多维度规则，支持混编）
- **连接观测**：实时连接列表，IP 归属地走 ip2region v4/v6 离线库
- **备份恢复**：仅设置 / 完整（含自建模式）两种备份，zip 载体，恢复带完整性校验
- **程序内更新**：主程序与内核均可在线更新，先下载后切换、全程不断网
- **便携**：单文件自包含（约 220 MB），数据全在 exe 同目录，不写注册表

支持协议：Socks5 / Shadowsocks / ShadowsocksR / WireGuard / Trojan / VMess / VLESS（UDP NAT FullCone 取决于服务端）。

兼容旧版 1.x 的节点与订阅配置（settings.json 可直接沿用）。

> 进程代理与 TUN 模式需要管理员权限运行。
